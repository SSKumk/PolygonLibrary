# Active Project Boundary

Этот файл фиксирует принятое решение по границе активного проекта и неактивных слоёв репозитория.

Статус: принято, перенос выполнен.

## Структура

```text
repo/
  AGENTS.md
  README.md

  .ai/
  .agents/

  active/
    CGLibrary/

  dependencies/
    AVLUtils/

  references/
    Materials/

  legacy/
    LDG_Convex_2D/
    Nastya/
    Reminiscence/

  archives/
    old-snapshots/
```

`CGLibrary` пишется именно так. Вариант `CGLibray` считается опечаткой.

## Слои репозитория

### Активный проект

- `active/CGLibrary/`

Назначение:

- основная рабочая папка проекта;
- содержит актуальное решение `CGLibrary.sln`;
- содержит ядро `CGLibrary/`, тесты `Tests/`, документацию `Documentation/`, журнал задач `todo.md` и журнал закрытых задач `done.md`.

Правило:

- обычные изменения кода, тестов, документации и структуры активного проекта делаются только здесь;
- перед изменениями читать `active/CGLibrary/README.md` и связанные документы из `active/CGLibrary/Documentation/`.

### Зависимости

- `dependencies/AVLUtils/`

Назначение:

- отдельный проект с AVL-структурами;
- активный `active/CGLibrary/CGLibrary/CGLibrary.csproj` ссылается на `..\..\..\dependencies\AVLUtils\AVLUtils\bin\Release\net8.0\AVLUtils.dll`.

Правило:

- считать `AVLUtils/` зависимостью активного проекта;
- не считать её частью обычной рабочей области активного проекта;
- не менять исходники зависимости без задачи, явно связанной с этой зависимостью.

### Справочные материалы

- `references/Materials/`

Назначение:

- материалы по алгоритмам, статьи, заметки, PDF, TeX и вспомогательные проекты;
- источник внешнего и исторического контекста для алгоритмов.

Правило:

- использовать как справочный слой;
- не менять в обычных задачах по активному проекту без отдельного решения;
- при переносе полезного знания в активную документацию фиксировать связь с источником.

### Старые проекты и исторический код

- `legacy/LDG_Convex_2D/`
- `legacy/Nastya/`
- `legacy/Reminiscence/`

Назначение:

- старые проекты, вычислительные материалы, прежние версии кода и исторические копии;
- слой для восстановления контекста и сравнения со старой структурой.

Правило:

- не считать частью активного проекта;
- считать материалом для чтения и переноса знаний;
- не чистить, не улучшать и не удалять без отдельного решения;
- если оттуда переносится полезный сценарий или правило, перенос фиксировать в активном месте.

### Архивы

- `archives/old-snapshots/`

Назначение:

- архивные `.7z`-снимки старых состояний `PolygonLibrary` и `AVLUtils`.

Правило:

- не изменять и не удалять в обычном рабочем процессе;
- рассматривать только как исторические снимки;
- любые действия с архивами требуют отдельного решения.

### Служебный слой работы с агентами

- `AGENTS.md`
- `.ai/`
- `.agents/skills/`

Назначение:

- `AGENTS.md` задаёт стартовые правила для агента;
- `.ai/` хранит рабочие материалы по наведению порядка;
- `.agents/skills/` хранит локальные скиллы репозитория.

Правило:

- эти файлы можно менять в рамках задач по организации работы агентов и документации;
- `.ai/` не должна подменять постоянную проектную документацию активного проекта.

## Общее правило работы

По умолчанию работать только в:

- `active/CGLibrary/`;
- `AGENTS.md`;
- `.ai/`;
- `.agents/skills/`.

Все остальные слои считаются неактивными для обычных задач.

Исключение возможно только если пользователь явно называет такую папку или задача отдельно касается справочных материалов, старого кода, архивов или зависимости.
