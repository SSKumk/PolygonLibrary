# Working Folder README

## Scope

Этот скилл применяется к `README.md`, который задаёт правила работы с папкой.

Использовать, когда README должен объяснить:

- для чего нужна папка;
- что в неё можно помещать;
- что в неё нельзя помещать;
- когда читать или менять файлы внутри;
- как чистить, архивировать или переносить содержимое;
- какие документы задают связанные правила.

Не использовать для чистого навигационного README. Для него использовать `navigation-readme`.

## Related Skills

При создании или правке такого README также использовать `repository-text-style`.

Если README одновременно содержит навигационный список, для этого списка использовать `navigation-readme`.

## Purpose

README рабочей папки должен быть локальным договором о поведении в этой папке.

Он должен отвечать не на вопрос "какие файлы здесь лежат вообще", а на вопрос "как с этой папкой обращаться".

## Required Questions

Перед написанием ответить:

1. Какова роль папки?
2. Кто и когда должен сюда идти?
3. Какие файлы здесь допустимы?
4. Какие файлы сюда не относятся?
5. Что считается временным, архивным или постоянным?
6. Когда содержимое нужно удалить, перенести или синхронизировать?
7. Где лежат связанные правила?

## Typical Shape

```md
# <FolderName>

Короткое назначение папки.

## Когда использовать

- ...

## Что здесь хранить

- ...

## Что сюда не класть

- ...

## Как работать с файлами

- ...

## Когда чистить или переносить

- ...

## Связанные правила

- [`File.md`](../File.md)
```

Не все разделы обязательны. Оставлять только те, которые реально нужны папке.

## What To Include

Включать:

- назначение папки;
- границу ответственности;
- разрешённые типы содержимого;
- запрещённые типы содержимого;
- правила жизненного цикла файлов;
- связи с постоянной документацией;
- правило удаления или архивирования, если папка временная или архивная.

## What To Avoid

Не добавлять:

- список всех файлов без правил работы;
- пересказ содержимого каждого файла;
- общие фразы вроде "папка нужна для удобства";
- правила, уже подробно зафиксированные в другом месте;
- обещания о будущем состоянии без конкретного действия.

## Checklist

Перед завершением проверить:

- README объясняет, как работать с папкой;
- есть ясная граница "класть / не класть";
- временное, архивное и постоянное содержимое не смешаны;
- связанные правила указаны ссылками;
- нет пересказа файлов вместо правил;
- текст короткий и прикладной.
