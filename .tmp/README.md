# .tmp

`.tmp/` - локальная рабочая папка для временных материалов текущих задач.

Сюда можно класть черновики, заметки, логи, медиа, диагностические файлы, временные данные, одноразовые скрипты и подпапки под конкретную задачу.

Содержимое `.tmp/` не является источником истины и не входит в постоянную документационную карту репозитория.

В Git попадает только этот `README.md`. Все остальные файлы внутри `.tmp/` игнорируются.

Если временный материал стал нужен постоянно, его переносят в код, тесты, документацию, `references/` или другой постоянный слой.
