# Archive

Архивный слой `CGLibrary`.

Сюда переносится код, который:
- больше не относится к целевой рабочей структуре;
- сохраняется ради истории, сравнения или отложенного анализа;
- не должен смешиваться с актуальными папками библиотеки.

Правило:
- новые рабочие сущности и алгоритмы сюда не добавляются;
- всё, что попадает в `Archive/`, должно либо быть явно legacy, либо ожидать отдельного решения о дальнейшем удалении или восстановлении.
