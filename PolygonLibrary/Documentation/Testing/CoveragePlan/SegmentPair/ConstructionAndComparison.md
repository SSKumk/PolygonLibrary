# SegmentPair Construction And Comparison

## Scope

Этот файл покрывает единственный конструктор `SegmentPair` и его `CompareTo`.

| ID | Status | Scenario | Tests |

| `SGP-CMP-002` | ` ` | Конструктор даёт одинаковый результат для `(a, b)` и `(b, a)`. | |
| `SGP-CMP-003` | ` ` | `CompareTo` сначала сравнивает `s1`, а затем `s2`. | |
