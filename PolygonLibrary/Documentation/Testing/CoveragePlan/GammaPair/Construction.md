# GammaPair Construction

## Scope

Этот файл покрывает конструкторы `GammaPair` и базовые инварианты хранения:

- значение по умолчанию;
- конструктор из нормали и значения;
- режим `ToNormalize`;
- копирующий конструктор.

## Scenarios

| ID | Status | Scenario | Tests |
| --- | --- | --- | --- |
| `GP-CTOR-001` | ` ` | Конструктор по умолчанию создаёт пару с нормалью `(1, 0)` и нулевым значением. | |
| `GP-CTOR-002` | ` ` | Конструктор `GammaPair(normal, value, false)` сохраняет нормаль и значение без преобразования. | |
| `GP-CTOR-003` | ` ` | Конструктор `GammaPair(normal, value, true)` нормализует нормаль до единичной длины. | |
| `GP-CTOR-004` | ` ` | Конструктор `GammaPair(normal, value, true)` масштабирует `Value` на ту же длину, что и нормаль. | |
| `GP-CTOR-005` | ` ` | Копирующий конструктор создаёт эквивалентную пару с теми же `Normal` и `Value`. | |
| `GP-CTOR-006` | ` ` | Конструктор запрещает нулевую нормаль согласно текущему debug-контракту. | |

## Gaps

- Нет прямых тестов на default ctor.
- Нет прямых тестов на режим `ToNormalize = true`.
- Нет отдельного сценария на нулевую нормаль.

## Notes

- Для `ToNormalize` нужно брать нормаль с длиной, отличной от `1`, и проверять обе величины: `Normal` и `Value`.
- Здесь пока лучше не считать косвенное использование конструктора в тестах `SupportFunction` достаточным прямым покрытием.
