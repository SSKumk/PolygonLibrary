# Line2D

## Scope

Класс [`CGLibrary/Basics/Line2D.cs`](F:\Works\IMM\Аспирантура\_PolygonLibrary\PolygonLibrary\CGLibrary\Basics\Line2D.cs) описывает прямую на плоскости в общем виде `Ax + By + C = 0` и хранит:

- коэффициенты общего уравнения;
- направляющий вектор;
- нормаль;
- ориентацию положительной полуплоскости;
- операции проверки принадлежности и пересечения двух прямых.
