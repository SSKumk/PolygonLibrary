# Collection Helpers

## Covered scenarios

- `EXT-COLL-001` `Subsets` возвращает все подмножества заданной длины в текущем рекурсивном порядке.
- `EXT-COLL-002` `AllSubsets` перечисляет все подмножества в bitmask-порядке, включая пустое и полное.
- `EXT-COLL-003` `LinkedList.CyclicShift` переносит первый элемент в конец.
- `EXT-COLL-004` `ToSortedSet` сортирует последовательность и убирает дубликаты.

## Notes

- Для `Subsets` и `AllSubsets` закрепляется именно текущий порядок перечисления, потому что он уже может быть значим для helper-использований в тестовом коде.
