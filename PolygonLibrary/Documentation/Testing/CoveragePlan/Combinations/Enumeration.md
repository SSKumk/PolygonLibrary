# Enumeration

## Covered scenarios

- `COMB-ENUM-001` Конструктор инициализирует стартовое состояние `0..k-1`.
- `COMB-ENUM-002` `Next()` перечисляет все сочетания в лексикографическом порядке.
- `COMB-ENUM-003` На максимальном состоянии `Next()` возвращает `false` и не меняет текущую комбинацию.

## Notes

- В active layer закрепляется zero-based текущий контракт.
- Проверка некорректных `n` и `k` остаётся на уровне `Debug.Assert` и не входит в runtime-покрытие.
