# Matrix Linear Operations

## Scope

Этот файл покрывает специальные фабрики и линейные операции `Matrix`.

## Scenarios

| ID | Status | Scenario | Tests |
| --- | --- | --- | --- |
| `MAT-LIN-001` | ` ` | `Zero(rows, cols)` создаёт нулевую матрицу заданной формы. | |
| `MAT-LIN-002` | ` ` | `One(rows, cols)` создаёт матрицу из единиц заданной формы. | |
| `MAT-LIN-003` | ` ` | `Eye(d)` создаёт единичную матрицу размера `d x d`. | |
| `MAT-LIN-004` | ` ` | `GenMatrix(dimRow, dimCol, a, b)` создаёт матрицу нужной формы с элементами в диапазоне `[a, b)`. | |
| `MAT-LIN-005` | ` ` | `GenMatrixInt(dimRow, dimCol, a, b)` создаёт матрицу нужной формы с целочисленными значениями в `[a, b)`. | |
| `MAT-LIN-006` | ` ` | `GenNonSingular(dim, a, b)` возвращает квадратную невырожденную матрицу. | |
| `MAT-LIN-007` | ` ` | `GenONMatrix(dim)` возвращает ортонормированную матрицу. | |
| `MAT-LIN-008` | ` ` | `Hilbert(dim)` создаёт матрицу Гильберта по формуле `1 / (i + j + 1)`. | |
| `MAT-LIN-009` | ` ` | `MultiplyRowByVector(rowInd, v)` вычисляет скалярное произведение строки на вектор. | |
| `MAT-LIN-010` | ` ` | `MultiplyRowByDiffOfVectors(rowInd, v1, v2)` эквивалентен произведению строки на `(v1 - v2)`. | |
| `MAT-LIN-011` | ` ` | `MultiplyColumnByVector(colInd, v)` вычисляет скалярное произведение столбца на вектор. | |
| `MAT-LIN-012` | ` ` | `ToRREF()` возвращает матрицу в приведённой ступенчатой форме для простого невырожденного примера. | |
| `MAT-LIN-013` | ` ` | `ToRREF()` корректно обрабатывает матрицу с линейно зависимыми строками. | |
| `MAT-LIN-014` | ` ` | `ToRREF()` не меняет матрицу, уже находящуюся в RREF. | |

## Gaps

- Нет прямого покрытия генераторов.
- Нет отдельного покрытия `ToRREF()` на вырожденных и прямоугольных примерах.

## Notes

- Для `GenNonSingular` и `GenONMatrix` удобнее проверять инварианты, а не конкретные значения.
- Для `ToRREF()` полезно иметь заранее известные эталонные матрицы и их форму результата.
