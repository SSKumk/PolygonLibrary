# Matrix Construction And Access

## Scope

Этот файл покрывает создание матриц, размеры, индексаторы и преобразование к массивам.

## Gaps

- Нет отдельной фиксации copy/no-copy семантики.
- Нет прямого покрытия линейного индексатора `[i]`.

## Notes

- Для сценариев с разделяемым хранилищем удобнее использовать `MatrixMutable` как инструмент наблюдения эффекта.
- Стоит проверять не только значения, но и форму результирующей матрицы.
