# Matrix Comparison And Formatting

## Scope

Этот файл покрывает `Equals`, `CompareTo` и строковое представление `Matrix`.

## Scenarios

| ID | Status | Scenario | Tests |
| --- | --- | --- | --- |
| `MAT-CMP-001` | ` ` | `Equals(Matrix)` возвращает `true` для матриц одинаковой формы и совпадающих элементов. | |
| `MAT-CMP-002` | ` ` | `Equals(Matrix)` возвращает `false` для матриц разной формы. | |
| `MAT-CMP-003` | ` ` | `Equals(Matrix)` возвращает `false` для матриц одинаковой формы, но с отличающимися элементами. | |
| `MAT-CMP-004` | ` ` | `Equals(object)` возвращает `true` для эквивалентного объекта типа `Matrix`. | |
| `MAT-CMP-005` | ` ` | `CompareTo` сначала сравнивает число строк. | |
| `MAT-CMP-006` | ` ` | `CompareTo` затем сравнивает число столбцов. | |
| `MAT-CMP-007` | ` ` | `CompareTo` при равной форме выполняет лексикографическое сравнение элементов. | |
| `MAT-CMP-008` | ` ` | `CompareTo` считает `null` меньшим, чем любая матрица. | |
| `MAT-CMP-009` | ` ` | `ToString()` выводит элементы построчно. | |
| `MAT-CMP-010` | ` ` | `ToString()` выравнивает столбцы по максимальной ширине текстового представления. | |

## Gaps

- Нет прямой фиксации формата `ToString()`.
- Не размечено поведение сравнения около `Eps`.

## Notes

- Для `CompareTo` нужны матрицы, различающиеся сначала формой, затем содержимым.
- Для `ToString()` лучше фиксировать небольшие примеры с числами разной длины.
