# Matrix Structure And Extraction

## Scope

Этот файл покрывает структурные операции `Matrix`: склейку, извлечение частей и транспонирование.

## Scenarios

| ID | Status | Scenario | Tests |
| --- | --- | --- | --- |
| `MAT-STR-001` | ` ` | `hcat(m1, m2)` горизонтально склеивает матрицы с одинаковым числом строк. | |
| `MAT-STR-002` | ` ` | `hcat(m, v)` добавляет вектор как последний столбец. | |
| `MAT-STR-003` | ` ` | Экземплярный `hcat(v)` эквивалентен статическому `hcat(this, v)`. | |
| `MAT-STR-004` | ` ` | `vcat(m, v)` добавляет вектор как последнюю строку. | |
| `MAT-STR-005` | ` ` | Экземплярный `vcat(v)` эквивалентен статическому `vcat(this, v)`. | |
| `MAT-STR-006` | ` ` | `TakeRows(start, count)` возвращает нужный диапазон строк в исходном порядке. | |
| `MAT-STR-007` | ` ` | `TakeCols(start, count)` возвращает нужный диапазон столбцов в исходном порядке. | |
| `MAT-STR-008` | ` ` | `TakeSubMatrix(startRow, rowCount, startCol, colCount)` извлекает правильный прямоугольный блок. | |
| `MAT-STR-009` | ` ` | `TakeRowVector(row)` возвращает строку как `Vector`. | |
| `MAT-STR-010` | ` ` | `TakeColumnVector(col)` возвращает столбец как `Vector`. | |
| `MAT-STR-011` | ` ` | `Transpose()` меняет размеры местами и переносит элементы по правилу `res[j, i] = src[i, j]`. | |
| `MAT-STR-012` | ` ` | Двойное транспонирование возвращает матрицу, эквивалентную исходной. | |

## Gaps

- Нет отдельной фиксации семейства `Take*`.
- Не зафиксирована согласованность instance/static вариантов `hcat` и `vcat`.

## Notes

- Для семейства `Take*` лучше использовать матрицу с уникальными значениями во всех ячейках.
- Для `Transpose()` полезно проверять как квадратную, так и прямоугольную матрицу.
