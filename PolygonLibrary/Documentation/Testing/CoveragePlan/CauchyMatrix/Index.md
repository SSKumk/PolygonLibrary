# CauchyMatrix

## Scope

Класс [`CauchyMatrix.cs`](../../../../CGLibrary/Basics/CauchyMatrix.cs) вычисляет фундаментальную матрицу для постоянной квадратной системы через схему Рунге-Кутты 4-го порядка.

В активный слой текущего этапа входят:

- значение в опорный момент `T`;
- нулевая матрица;
- диагональная матрица с известным точным ответом;
- частичный шаг интегрирования на матрице с простым замкнутым видом решения в прямом и обратном времени.
