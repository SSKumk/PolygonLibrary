# Documentation

Основная документация проекта.

Если правило относится ко всему репозиторию, оно фиксируется здесь или в документе, на который этот индекс ссылается.

## Навигация

- [`DocumentationConventions.md`](./DocumentationConventions.md)
  Объект: общие соглашения по текстовой документации репозитория.
  Когда использовать: когда нужно сверить правила оформления документации перед созданием или правкой `.md`-файла.

- [`Development/README.md`](./Development/README.md)
  Объект: внутренняя документация по разработке, соглашениям и инженерным договорённостям.
  Когда использовать: когда нужен источник инженерных правил для изменения кода, структуры проекта или developer-facing документации.

- [`References/README.md`](./References/README.md)
  Объект: каталог внешних источников, статей и reference-материалов, на которые опираются алгоритмы библиотеки.
  Когда использовать: когда нужно найти внешний источник для алгоритма или понять, на какой reference-материал уже опирается конкретная реализация.

- [`Testing/README.md`](./Testing/README.md)
  Объект: документация по тестовому покрытию, миграции тестов и текущему состоянию проверок.
  Когда использовать: когда нужно сверить правила тестового слоя, текущее покрытие и обязательные сопутствующие обновления документации.
