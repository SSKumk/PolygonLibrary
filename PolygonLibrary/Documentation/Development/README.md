# Development

Эта папка содержит внутреннюю документацию по разработке библиотеки.

## Навигация

- [`../DocumentationConventions.md`](../DocumentationConventions.md)
  Объект: общие соглашения по текстовой документации репозитория.
  Когда использовать: когда нужно понять, как оформлять навигационные `.md`-файлы, как избегать дублирования и какое кодирование текста обязательно.

- [`RepoStructure.md`](./RepoStructure.md)
  Объект: компактный обзор структуры репозитория.
  Когда использовать: когда нужно быстро понять, где живут основные подсистемы проекта и в какую папку идти за нужным кодом или документацией.

- [`CodingConventions.md`](./CodingConventions.md)
  Объект: общий свод соглашений по оформлению, документированию и инженерным конвенциям кода.
  Когда использовать: когда нужно понять, как в библиотеке оформляются XML-комментарии, какие требования предъявляются к внутреннему и внешнему API и какие правила считаются обязательными.

- [`LibPolytopeFormat.md`](./LibPolytopeFormat.md)
  Объект: рабочее описание формата `LibPolytope`.
  Когда использовать: когда нужно разобраться в представлении данных `LibPolytope` или синхронизировать код с этим форматом.

- [`PolyhedraNaming.txt`](./PolyhedraNaming.txt)
  Объект: рабочая памятка по именованию многогранников.
  Когда использовать: когда нужно сверить историческое или внутреннее именование тестовых и геометрических объектов.
