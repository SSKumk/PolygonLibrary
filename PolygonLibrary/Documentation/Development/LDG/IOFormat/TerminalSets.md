## Структура файла

```
TSType = S;  // Тип терминального множества
[описание терминального множества]
```

Корректные значения `TSType`: `Explicit`, `Minkowski`, `Epigraph`, `LevelSet`

В зависимости от значения поля `TSType` дальнейшая структура файла будет различной.

### Explicit

Терминальные множества заданы набором имён явных многогранников (см [explicit](./Polytopes.md)) из папки `Polytopes`. Мосты строятся от каждого из них.

```
Polytopes = 1D<S>;  // список имён многогранников
```

Пример

```
TSType = "Explicit";
Polytopes = {"2D-Circle"}; // Список имен файлов многогранников
```

---

### Minkowski

Терминальные множества представляют собой набор многогранников, полученных умножением данного по имени явного многогранника (см [explicit](./Polytopes.md)) из папки `Polytopes` на указанные константы. Мосты строятся от каждого из них.

```
Polytope  = S;      // имя многогранника
Constants = 1D<D>;  // набор констант, на которые умножится многогранник
```

Пример

```
TSType = "Minkowski";
Polytope  = "2D-Square";       // Имя многогранника из папки /Polytopes
Constants = {1.0, 1.5};   // Построить 2 множества: 1*Square, 1.5*Square
```

### Epigraph

Строится мост от срезки надграфика предустановленной функции.

```
Type = S;      // тип функции платы
ScaleFactor = D;  // константа, на которой происходит отсечение надграфика функции
[описание типа]
```

Корректные значения `Type`: `DistToPointByNorm`, `DistToPointByUnitBall`,`DistToPolytopeByNorm`, (todo: `DistToPolytopeByUnitBall`)

* `DistToPointByUnitBall` -- расстояние до данной точки в метрике, задаваемой данным многогранником;
* `DistToPointByNorm` -- расстояние до данной точки ($l_1$, $l_2$, $l_{inf}$);
* `DistToPolytopeByNorm` -- расстояние до данного многогранника ($l_1$, $l_2$, $l_{inf}$).

#### DistToPointByUnitBall

```
Point = 1D<D>;  // координаты точки расстояние до которой интересует 
UnitBall = S;  // имя многогранника (из папки Polytopes). Его 'центр'  должен быть в начале координат
```

Пример

```
TSType = "Epigraph";
Type = "DistToPointByUnitBall";
ScaleFactor = 2;  // константа, на которой происходит отсечение надграфика функции
Point = {0,0};
UnitBall = "2D-Circle";
```

#### DistToPointByNorm

```
Point = 1D<D>;  // координаты точки
BallType = S;  // норма шара ('Ball_1', 'Ball_2', 'Ball_oo')
[описание для Ball_2, если выбрана Евклидова норма]
```

Пример

```
TSType = "Epigraph";
Type = "DistToPointByNorm"
ScaleFactor = 2;
Point = {0,0};
BallType = Ball_2;
AzimuthsDivisions = 6; // Количество точек разбиения сферы по каждому из азимутных углов.
PolarDivision = -1; // Количество точек разбиения сферы по зенитному углу. В 2д случае неважно чему равно это поле.
```

### LevelSet

Строится мост от каждого из множеств уровня предустановленной функции платы.

```
Type      = S;      // тип функции
[описание типа]
Constants = 1D<D>;  // набор констант, для которых считается множество уровня
BallType  = S;      // Норма шара
[описание, в случае Евклидовой нормы]
```

Корректные значения `Type`: `DistToPoint`, `DistToPolytope`

* `DistToPoint` -- множество уровня функции расстояния до точки (множество точек, равноудаленных от указанной точки в заданной норме)
* `DistToPolytope` -- множество уровня функции расстояния до многогранника

## Предопределённые нормы шаров

Корректные значения поля `BallType`: `Ball_1`, `Ball_2`, `Ball_oo`

* `Ball_1`  -- сумма модулей координат: $\sum_{i=1}^n |x_i|$ (норма $l_1$).
* `Ball_2`  -- Евклидова норма: $\sqrt{\sum_{i=1}^n x_i^2}$ (норма $l_2$).
* `Ball_oo` -- Чебышёвская норма: $\max_i{|x_i|}$  (норма $l_{inf}$).

_Ball_1_, _Ball_oo_ -- не требуют дополнительного описания

**_Ball_2_**

```
PolarDivision = N; // Количество точек разбиения сферы по зенитному углу.
AzimuthsDivisions = N; // Количество точек разбиения сферы по каждому из азимутных углов. В 2д случае неважно чему равно это поле -- при чтении оно игнорируется.
```
