# XML And Working Files

Этот файл фиксирует правила по XML-комментариям и по временным рабочим файлам.

Общее правило: писать только факты, только по делу, без пустых общих фраз.

## XML Comments

### Когда писать XML

- XML пишется для `public`, `protected`, `internal` и `private` сущностей, если они выражают контракт, инвариант, алгоритмический смысл или нетривиальную механику.
- XML обновляется одновременно с изменением кода.
- Если меняется контракт, поведение, инвариант или смысл метода, XML меняется в том же коммите.

### Как писать XML

- `summary` отвечает на вопрос, что делает сущность.
- `remarks` используются только если нужно зафиксировать алгоритм, инвариант, соглашение хранения, условия корректности или важное отличие от соседнего API.
- `param`, `returns` и `exception` пишутся только там, где они реально добавляют факт о контракте.
- Для алгоритмических классов и методов описывать нужно сам алгоритм, математику и форму преобразования данных.
- Не писать текст вида:
  - "This class contains useful methods"
  - "This method processes data"
  - "Represents some object"
- Если смысл уже очевиден из сигнатуры и имени, повторять его другими словами не нужно.

### Что обязательно фиксировать

- для классов: что представляет тип и чем он отличается по контракту от соседних типов;
- для конструкторов: что они строят и какие ограничения накладывают на вход;
- для методов мутации: что именно меняется и какие кэши или инварианты это затрагивает;
- для low-level алгоритмов: какую матричную, геометрическую или численную операцию выполняет метод;
- для helper-методов: только ту часть поведения, без которой трудно понять код.

## TempNotes

- Временные заметки живут только в [`../../TempNotes/README.md`](../../TempNotes/README.md) и соседних файлах этой папки.
- Временный файл создаётся только под текущую задачу:
  - план;
  - диагностический лог;
  - черновик алгоритма;
  - рабочая таблица решений.
- Временный файл не является source of truth.
- Если содержимое стало постоянным знанием, его нужно перенести в `Documentation/...`, а временный файл удалить.
- После завершения задачи временный файл удаляется.
- `TempNotes` содержимое не коммитится; коммитить туда можно только её собственный `README`.
