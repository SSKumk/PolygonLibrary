# Repo Structure

Компактный обзор структуры репозитория.

## CGLibrary

Объект: ядро библиотеки геометрических вычислений.
Когда использовать: когда нужно искать реализацию математических объектов, геометрических структур и вычислительных алгоритмов.

- `Basics/` - базовые векторы, матрицы, базисы, гиперплоскости и связанные с ними операции.
- `LinearMath/` - линейная алгебра, оптимизация и низкоуровневые вычислительные алгоритмы.
- `Polygons/` - 2D-полигональная геометрия, полилинии и выпуклые полигоны.
- `Polyhedra/` - многогранники, решётки граней и многомерная выпуклая геометрия.
- `Segments/` - отрезки и операции над ними.
- `Toolkit/` - общие утилиты, числовые соглашения и служебные helper-методы.
- `Archive/` - архивный и legacy-код, который не относится к целевой рабочей структуре.

## Tests

Объект: тестовый проект и вспомогательные материалы для проверки библиотеки.
Когда использовать: когда нужно найти существующие тесты, test helpers или понять, как организован активный тестовый слой.

- `DoubleGeometry/` - новый основной слой тестов для `double`.
- `SharedTests/` - legacy-слой, который постепенно вытесняется миграцией.
- `ToolsForTests/` - генераторы тестовых данных и общие хелперы.

## Documentation

Объект: основная документация репозитория.
Когда использовать: когда нужно понять правила разработки, структуру тестовой документации и форматы данных.

- `DocumentationConventions.md` - общие правила текстовой документации.
- `Development/` - документация по разработке, форматам и устройству репозитория.
- `Testing/` - документация по покрытию тестами и статусу миграции.

## LDG

Объект: прикладной слой для линейных дифференциальных игр.
Когда использовать: когда нужно работать с предметной областью LDG, форматами её данных и прикладными алгоритмами над геометрическим ядром.

## Auxiliary Directories

Объект: вспомогательные проекты и рабочие каталоги вокруг основного ядра.
Когда использовать: когда задача уже выходит за рамки `CGLibrary` и её тестов.

- `Graphics/` - графические и визуализационные материалы.
- `Profile/` - профилирование и benchmark-артефакты.
- `Sandbox/` - экспериментальная рабочая зона.
- `Trajectories/` - данные и материалы по траекториям.
- `Bridges/` - связанные данные и материалы по мостам.

## Root Files

Объект: файлы верхнего уровня репозитория.
Когда использовать: когда нужно понять общую конфигурацию solution и рабочие списки задач.

- `CGLibrary.sln` - основная solution.
- `README.md` - корневой индекс документации.
- `todo.md` / `TODO.txt` - рабочие списки задач и заметки.
- `AGENTS.md` - локальные инструкции для AI-агентов.
