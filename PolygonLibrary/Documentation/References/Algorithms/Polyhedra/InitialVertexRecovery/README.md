# Initial Vertex Recovery References

Папка для заметок и reference-материалов по восстановлению стартовой вершины по `Hrep` в
[`ConvexPolytop.cs`](../../../../../CGLibrary/GeometryND/Polyhedra/ConvexPolytop.cs).

## Как использовать

- Класть сюда алгоритмические заметки по `FindInitialVertex_Simplex` и связанному доведению simplex-optimum до вершины.
- В этом файле кратко фиксировать:
  - что это за материал;
  - какие части `ConvexPolytop` или тестов на восстановление вершины на него опираются.
