# References

Каталог внешних источников, на которые опираются алгоритмы и форматы библиотеки.

## Навигация

- [`Algorithms/README.md`](./Algorithms/README.md)
  Объект: ссылки на статьи и reference-материалы для алгоритмических слоёв библиотеки.
  Когда использовать: когда нужно найти источник для конкретного алгоритма или понять, на какую публикацию опирается его реализация.

## Правила

- В эту ветку кладутся только внешние источники: статьи, preprint-версии, заметки по алгоритмам и сопровождающие reference-материалы.
- Для каждой папки алгоритма нужен локальный `README.md`, который отвечает на два вопроса:
  - что это за источник;
  - для какого алгоритма и какого участка кода он используется.
- Если источник большой или содержит несколько версий, в `README.md` нужно явно указать, какая версия считается рабочей для библиотеки.
