# .ai

Эта папка хранит вспомогательные документы для навигации по репозиторию и быстрой ориентации в проекте.

Содержимое:

- `ProjTree.md` — дерево проекта с пояснениями по папкам, проектам и ключевым файлам.

Замечания:

- Это не замена основной документации из `Documentation/`.
- В описании дерева сознательно не расписываются `bin/`, `obj/`, `.idea/`, `.vscode/` и прочие сгенерированные/IDE-артефакты.
- Документ стоит обновлять, если в solution появляются новые проекты или заметно меняется структура каталогов.
