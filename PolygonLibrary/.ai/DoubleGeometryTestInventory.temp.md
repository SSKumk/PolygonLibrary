# Double Geometry Test Inventory

Временный рабочий документ.

Цель: перечислить, что именно должно быть покрыто тестами для базовой геометрии при использовании
`Geometry<double, Tests.DConvertor>`, не пиша сами тесты.

Границы этого списка:

- Включено: базовые геометрические сущности, операции над ними, базовые 2D/ND геометрические алгоритмы, выпуклые полигоны, отрезки, многогранники.
- Не включено пока: LDG, консольные entry point-проекты, Benchmark/Profile, файловая инфраструктура вокруг приложений.
- Частично включено: матрично-линейная база постольку, поскольку она поддерживает геометрические операции.
- Не детализируется пока: pure optimization-пайплайн уровня `SimplexMethod` / `FourierMotzkin` как самостоятельная математическая подсистема, если он не нужен для явных геометрических контрактов.

## `CGLibrary/Toolkit/Tools.cs`

  - Сценарии тестирования:

    - поведение на значениях около границы `eps`
    - симметрия и транзитивность в допустимых для epsilon-подхода пределах
    - изменение `Eps` и связанное изменение `EpsG`
    - `Sign`, `Abs`, `Atan2` на типовых квадрантах и граничных случаях
    - генерация сочетаний
    - swap / служебные helper-методы

## Предлагаемая следующая стадия

На следующем шаге удобно пройти по этому списку и для каждого объекта поставить один из статусов:

- `уже покрыто достаточно`
- `покрыто частично`
- `не покрыто`
- `не входит в минимальный обязательный набор`

После этого можно формировать список конкретных недостающих тестов только для `double`.
