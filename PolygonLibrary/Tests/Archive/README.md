# Archive

Архивный слой для старых тестов и крупных legacy-наборов, которые больше не относятся к активному тестовому покрытию.

## Как использовать

- Сюда переносятся исторические тестовые файлы, которые больше не должны участвовать в обычной компиляции и регулярных прогонах.
- Архив сохраняется как reference-слой:
  - для восстановления отдельных сценариев;
  - для сравнения со старой структурой;
  - для выборочного переноса полезных кейсов в новый активный слой.
