# TempNotes

`TempNotes` — папка для временных рабочих заметок по текущей задаче.

Общее правило: в файлах этой папки писать только рабочие факты, решения и шаги. Не писать пустые общие фразы.

## Когда создавать файл

Создавать временный файл здесь имеет смысл, если по задаче нужен:

- короткий рабочий план с этапами;
- черновик алгоритма;
- список инвариантов перед рефакторингом;
- диагностическая сводка по расследованию;
- таблица решений, которую неудобно держать в чате.

## Когда не создавать файл

- если задача решается без промежуточных заметок;
- если информация уже должна жить в постоянной документации;
- если файл будет дублировать существующий `README` или coverage-документ.

## Как работать с файлами

- каждый файл здесь относится к одной текущей задаче;
- имя файла должно сразу говорить, о какой задаче он;
- содержимое должно быть кратким и рабочим;
- файл не должен считаться постоянной документацией проекта.

## Когда удалять файл

- как только задача закрыта;
- или как только полезное содержимое перенесено в `Documentation/...`.

Если временная заметка превратилась в постоянное описание алгоритма, процесса или контракта:

1. перенести итоговую информацию в `Documentation/...`;
2. удалить временный файл;
3. не оставлять две версии одного и того же текста.
