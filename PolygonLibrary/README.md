# PolygonLibrary

`CGLibrary` - библиотека геометрических вычислений.

Корневой `README` служит только индексом и не дублирует подробную документацию.

Общее правило для README-файлов: писать только факты, только по делу, без пустых общих фраз.

## Навигация

- [`Documentation/README.md`](./Documentation/README.md)
  Объект: корневой индекс проектной документации.
  Когда использовать: когда ещё неясно, в каком разделе документации лежит нужное правило, reference-материал или тестовый статус.

- [`Documentation/Development/README.md`](./Documentation/Development/README.md)
  Объект: документация по разработке и общим соглашениям по коду.
  Когда использовать: когда нужно сверить инженерные правила разработки перед изменением кода или структуры проекта.

- [`Documentation/Development/XMLAndWorkingFiles.md`](./Documentation/Development/XMLAndWorkingFiles.md)
  Объект: правила по XML-комментариям и по временным рабочим файлам.
  Когда использовать: когда нужно понять, как документировать код, когда писать XML и как обращаться с временными заметками.

- [`Documentation/Testing/README.md`](./Documentation/Testing/README.md)
  Объект: документация по тестовому покрытию и миграции тестов.
  Когда использовать: когда нужно понять, как в проекте оформляется тестовое покрытие, где фиксируется его статус и какие документы надо обновлять вместе с тестами.

- [`TempNotes/README.md`](./TempNotes/README.md)
  Объект: правила по временной рабочей папке `TempNotes`.
  Когда использовать: когда для текущей задачи нужен временный план, черновик алгоритма или диагностическая заметка.
