# Profile

Папка для LDG-ориентированных profiling/benchmark-сценариев, вынесенных из `active/CGLibrary/Profile`.

## Навигация

- [`Profile.csproj`](./Profile.csproj)
  Объект: проект LDG-профилирования на `BenchmarkDotNet`.
  Когда использовать: когда нужно собрать или запустить benchmark-сценарии, связанные с LDG.

- [`Profile.cs`](./Profile.cs)
  Объект: ручной LDG-профильный entrypoint и заготовки сценариев.
  Когда использовать: когда нужно восстановить или адаптировать ручной прогон LDG-проверок.

- [`Benchmarks/`](./Benchmarks/)
  Объект: benchmark-классы для ручных LDG-сценариев.
  Когда использовать: когда нужно править или запускать LDG-бенчмарки.

- [`Наблюдения и результаты/`](./Наблюдения%20и%20результаты/)
  Объект: текстовые заметки и результаты запусков LDG-профилирования.
  Когда использовать: когда нужно сверить прошлые измерения и контекст ручных прогонов.
