# LDG

Активный слой для проекта LDG (линейные дифференциальные игры), выделенный из `active/CGLibrary`.

## Навигация

- [`Documentation/README.md`](./Documentation/README.md)
  Объект: индекс LDG-документации по форматам данных и структуре рабочих папок.
  Когда использовать: когда нужно найти правила формата LDG-файлов и связанные организационные документы.

- [`todo.md`](./todo.md)
  Объект: рабочий backlog активного LDG-слоя.
  Когда использовать: когда нужно найти открытые задачи по LDG, мостам, траекториям, визуализации или структуре LDG-данных.

- [`done.md`](./done.md)
  Объект: журнал закрытых LDG-задач.
  Когда использовать: когда нужно проверить, какие LDG-решения уже были приняты и сняты с активного backlog.

- [`LDG/`](./LDG/)
  Объект: исходный код и проект `LDG.csproj`.
  Когда использовать: когда нужно изменять или собирать ядро LDG без перехода в остальные слои `CGLibrary`.

- [`Apps/`](./Apps/)
  Объект: запускатели LDG (`Bridges`, `Trajectories`) и их локальная навигация.
  Когда использовать: когда нужно запускать прикладные сценарии LDG и работать с проектами приложений отдельно от ядра `LDG`.

- [`Visualization/`](./Visualization/)
  Объект: слой визуализации LDG и навигация по проектам отображения результатов.
  Когда использовать: когда нужно работать с графической визуализацией результатов и соответствующими запускателями.

- [`Manual/`](./Manual/)
  Объект: ручные сценарии и песочницы для локальной проверки LDG-идей.
  Когда использовать: когда нужно вручную проверять гипотезы и небольшие изменения в LDG-сценариях.

- [`Profile/`](./Profile/)
  Объект: LDG-ориентированные profiling/benchmark-сценарии и их заметки.
  Когда использовать: когда нужно запускать или поддерживать ручные LDG-профили и benchmark-измерения.

- [`LDG.sln`](./LDG.sln)
  Объект: solution активного LDG-проекта.
  Когда использовать: когда нужно собрать LDG отдельно от solution геометрической библиотеки.
