# LDG

Активный слой для проекта LDG (линейные дифференциальные игры), выделенный из `active/CGLibrary`.

## Навигация

- [`LDG/`](./LDG/)
  Объект: исходный код и проект `LDG.csproj`.
  Когда использовать: когда нужно изменять или собирать ядро LDG без перехода в остальные слои `CGLibrary`.

- [`LDG.sln`](./LDG.sln)
  Объект: solution активного LDG-проекта.
  Когда использовать: когда нужно собрать LDG отдельно от solution геометрической библиотеки.
