# LDG Games Metadata

Папки игровых постановок с отобранными метаданными из внешнего `_Out`.

## Что здесь хранить

- `.gameconfig` в корне папки конкретной игры;
- `Trajectories/!Configs/*.trajconfig` для настроек траекторий.

## Что сюда не класть

- результаты расчётов мостов и вектограмм (`Br`, `Ps`, `Qs`);
- output-файлы траекторий (`game.traj`, `.times`, `fp.control`, `sp.control`, `fp.aim`, `sp.aim`);
- временные, кэш- и build-артефакты.

## Как работать с файлами

- Иерархию папки игры сохранять в формате из `../../Documentation/GameFolderStructure.md`.
- При добавлении новых наборов метаданных поддерживать разделение между входными данными (`../Dynamics`, `../Polytopes`, `../Terminal Sets`) и расчётными результатами.
