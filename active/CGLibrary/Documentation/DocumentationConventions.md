# Documentation Conventions

Этот файл фиксирует общие соглашения по текстовой документации репозитория.

## Navigation Links

Для обзорных `.md`-файлов, которые служат навигацией по подсистемам, правила такие:

- ссылки оформляются так, чтобы рядом с каждой ссылкой были даны два ответа:
  - что это за объект;
  - когда его использовать;
- обзорный `README` отвечает за навигацию, а не за пересказ содержимого подпапки;
- навигационный файл не должен дублировать содержимое целевого документа, а должен только помогать найти нужный объект и понять, зачем к нему идти;
- одна и та же информация не должна повторяться в нескольких обзорных файлах без необходимости;
- если правило или договорённость уже зафиксированы в одном месте, остальные документы должны ссылаться на это место, а не переписывать его заново.
- текст в обзорных документах должен оставаться компактным.
- при создании, удалении или переносе смысловой папки, документа или рабочего слоя нужно проверить ближайшие навигационные `README.md` и обновить ссылки, если маршрут изменился.

## Temporary Documents

- временный документ должен быть явно помечен в названии или в первых строках файла;
- если временный документ больше не нужен, его удаляют или архивируют, а не оставляют как будто он постоянный.

## Text Encoding

Весь текст в репозитории пишется только в `UTF-8`.

Это относится к:

- документации `.md`;
- XML-комментариям в коде;
- служебным текстовым файлам, если для них не задано более жёсткое внешнее ограничение формата.
