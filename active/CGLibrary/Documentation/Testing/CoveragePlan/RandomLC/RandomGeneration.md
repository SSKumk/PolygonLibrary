# Random Generation

## Covered scenarios

- `RLC-GEN-001` `NextInt` детерминирован для одинакового seed и соблюдает границы явного целочисленного диапазона.
- `RLC-GEN-002` `NextDouble` детерминирован для одинакового seed и остаётся внутри запрошенного вещественного диапазона.
- `RLC-GEN-003` `GRandomLC.NextPrecise` и `GRandomLC.NextFromInt` детерминированы и сохраняют границы диапазона.
- `RLC-GEN-004` `GenArray` использует переданный генератор и сохраняет размерность результата.
- `RLC-GEN-005` `GenArrayInt` использует переданный генератор, сохраняет размерность и возвращает только целые значения из допустимого диапазона.

## Notes

- Для `RandomLC` закрепляется детерминированный текущий контракт при заданном `seed`, а не статистическое качество генератора.
- Для вещественных генераторов верхняя граница трактуется по текущей реализации, без попытки закрепить строгую полуинтервальную семантику.
