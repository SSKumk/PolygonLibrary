# Param File Format

Формат описывает синтаксис файлов, которые читает `ParamReader`.

## Поле

```text
FieldName = Value;
```

Поля не чувствительны к пробелам и переносам строк.

Формат регистрозависимый.

Порядок полей важен, если конкретный reader читает файл последовательно.

Однострочный комментарий начинается с `//`.

Имя поля не должно содержать `{`, `}`, `,`, `=`, пробел, `\t`, `\n`, `\r`.

## Типы значений

- `B` - логическое значение: `true`, `false`.
- `N` - целое число: `-5`, `3`, `76`.
- `D` - вещественное число в записи через точку или в научной записи: `1e-14`, `10E4`, `-7.124`.
- `S` - строка в двойных кавычках. Поддерживаемые escape-последовательности: `\\`, `\"`, `\n`, `\r`, `\t`.
- `1D<T>` - одномерный массив элементов типа `T`: `{s0, s1, ..., sn}`.
- `2D<T>` - двумерный массив элементов типа `T`: `{{g00, g01}, {g10, g11}}`.

## Условный блок

Если в описании формата встречается блок:

```text
Field = B;
[parameters]
```

то блок `[parameters]` присутствует только при значении `Field = true`.
