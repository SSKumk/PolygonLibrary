# MinkowskiDiff References

Папка для статей и внешних материалов по алгоритму [`MinkowskiDiff.cs`](../../../../../CGLibrary/Algorithms/Polyhedra/MinkowskiDiff.cs).

## Как использовать

- Класть сюда статьи, конспекты внешних источников и reference-материалы по разности Минковского и связанным преобразованиям.
- В этом файле кратко фиксировать:
  - что это за источник;
  - какие части `MinkowskiDiff` или его тестов на него опираются.
