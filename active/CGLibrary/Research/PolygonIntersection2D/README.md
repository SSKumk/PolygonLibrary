# PolygonIntersection2D

Материалы по пересечению выпуклых 2D-многоугольников.

## Когда использовать

- когда нужно посмотреть reference-картинки для тестовых сценариев `ConvexPolygon.IntersectionPolygon`;
- когда нужно связать тесты пересечения с наглядными материалами без хранения картинок в `Tests/`.

## Навигация

- [`References/ConvexIntersectionFigures/`](./References/ConvexIntersectionFigures/)
  Объект: набор картинок и исходный `.lorien`-файл для сценариев пересечения выпуклых полигонов.
  Когда использовать: когда нужно визуально сверить тест-кейсы вида `TestX-Y` из intersection-тестов.
