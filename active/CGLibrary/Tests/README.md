# Tests

Активный тестовый проект геометрической библиотеки.

## Навигация

- [`Tests.csproj`](./Tests.csproj)
  Объект: проект тестов `CGLibrary`.
  Когда использовать: когда нужно собрать или открыть активный тестовый слой.

- [`DoubleGeometry/README.md`](./DoubleGeometry/README.md)
  Объект: основной слой быстрых `double` regression-тестов.
  Когда использовать: когда нужно найти или добавить обычный тест поведения геометрической библиотеки.

- [`Manual/README.md`](./Manual/README.md)
  Объект: ручные `[Explicit]`-песочницы внутри тестового проекта.
  Когда использовать: когда нужно быстро проверить гипотезу без оформления постоянного regression-теста.

- [`TestInfrastructure/README.md`](./TestInfrastructure/README.md)
  Объект: общая тестовая инфраструктура, генераторы и helper-слой.
  Когда использовать: когда helper нужен нескольким наборам тестов или требуется общий генератор тестовых данных.

- [`../Documentation/Testing/README.md`](../Documentation/Testing/README.md)
  Объект: правила и документация тестового покрытия.
  Когда использовать: когда нужно понять, какие coverage-документы обновлять вместе с тестами.
