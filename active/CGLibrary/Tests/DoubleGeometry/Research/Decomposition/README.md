# Decomposition Research

Что это: минимальный воспроизводимый research-набор по численным границам low-level decomposition primitives.

Когда использовать:
- когда нужно быстро воспроизвести репрезентативные численные пределы `QR_ByHouseholder`;
- когда нужно понять, где QR ещё годится как factorization, но уже плохо годится как rank-sensitive процедура.

Файлы:
- `QRStabilityResearchTests.cs` - минимальный набор по устойчивости `QR_ByHouseholder`.
