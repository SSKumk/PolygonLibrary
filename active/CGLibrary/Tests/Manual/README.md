# Manual Tests

Папка содержит ручные тестовые песочницы для быстрых проверок внутри тестового проекта.

## Когда использовать

- когда нужно временно проверить гипотезу через NUnit runner;
- когда отдельный regression-тест ещё рано оформлять;
- когда проверка не должна попадать в обычный тестовый прогон.

## Что здесь хранить

- только `[Explicit]`-тесты;
- короткие ручные sandbox-сценарии без внешних локальных путей;
- код, который легко удалить или превратить в полноценный тест.

## Что сюда не класть

- постоянные regression-тесты;
- performance/benchmark-сценарии;
- большие исследовательские прогоны;
- локальные данные и заметки.

## Как работать

- Обычные тестовые прогоны не должны запускать содержимое этой папки.
- Если сценарий стал полезным как проверка поведения, перенести его в `DoubleGeometry/` и добавить coverage-документ.
- Если сценарий больше не нужен, удалить его.
