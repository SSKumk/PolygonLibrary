# GiftWrapping Legacy

Что это:
- архивный legacy-набор `GW_Tests` для `double`;
- сопроводительный исторический текст по диапазонам генерации точек.

Когда использовать:
- когда нужно восстановить старый массовый сценарий или сверить новый слой со старым;
- когда нужно вернуться к pathological и исследовательским примерам, не входящим в активный слой.

## Notes

- Основные `Basic`, `Regression` и representative `Stress` сценарии уже перенесены в `Tests/DoubleGeometry/Algorithms/GiftWrapping`.
- Закомментированный `Simplex4D_PointCloseToVertex` сохраняется здесь как численно-патологический исследовательский пример, а не как обязательный активный тест.
