# External Binaries

Папка содержит бинарники, которые не подключены к активному проекту.

## Навигация

- [`MultiPrecision.dll`](./MultiPrecision.dll)
  Объект: потенциальная численная зависимость без текущего подключения к активным проектам.
  Когда использовать: когда будет проектироваться проверка новых численных типов.

- [`PolygonLibrary_old_net7.dll`](./PolygonLibrary_old_net7.dll)
  Объект: старый бинарный снимок прежней версии `PolygonLibrary`.
  Когда использовать: когда нужно сравнить поведение со старой сборкой или разобрать исторический сценарий.
