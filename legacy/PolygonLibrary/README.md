# PolygonLibrary

Исторический слой старого проекта `PolygonLibrary`.

## Навигация

- [`CGLibrary/`](./CGLibrary/)
  Объект: старые материалы библиотеки, сохранённые в исторической структуре проекта.
  Когда использовать: когда нужно сравнить активное ядро `CGLibrary` со старой реализацией или восстановить отложенный алгоритм.

- [`Tests/`](./Tests/)
  Объект: старые тестовые данные и конвертеры, вынесенные из активного тестового слоя.
  Когда использовать: когда нужно восстановить исторические входные данные или сравнить старый формат тестовых артефактов с активным проектом.
