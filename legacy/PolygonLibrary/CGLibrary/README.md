# CGLibrary

Исторические материалы старого `PolygonLibrary`, сохранённые с прежними путями относительно папки библиотеки.

## Навигация

- [`Archive/`](./Archive/)
  Объект: старый архивный код ядра библиотеки.
  Когда использовать: когда нужно восстановить прежнюю реализацию или сравнить старые классы с активным кодом.

- [`Geometry2D/Segments/Bentley-Ottmann/`](./Geometry2D/Segments/Bentley-Ottmann/)
  Объект: историческая заготовка алгоритма Bentley-Ottmann.
  Когда использовать: когда нужно вернуться к реализации пересечения отрезков через sweep line.

- [`PolygonLibrary.sln`](./PolygonLibrary.sln)
  Объект: старая solution с прежним именем проекта.
  Когда использовать: когда нужно понять историческую конфигурацию старого проекта.
