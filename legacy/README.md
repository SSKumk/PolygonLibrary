# Legacy

Папка содержит исторические проекты, старый код и прежние рабочие материалы.

## Навигация

- [`LDG_Convex_2D/`](./LDG_Convex_2D/)
  Объект: исторический слой по линейным дифференциальным играм и выпуклой двумерной геометрии.
  Когда использовать: когда нужно восстановить старый контекст LDG или сравнить с активным проектом.

- [`PolygonLibrary/`](./PolygonLibrary/)
  Объект: исторические материалы старого проекта `PolygonLibrary`, вынесенные из активного `CGLibrary`.
  Когда использовать: когда нужно восстановить старую реализацию, сравнить с активным ядром или разобрать отложенный алгоритм.

- [`Nastya/`](./Nastya/)
  Объект: исторические материалы отдельного старого рабочего направления.
  Когда использовать: когда задача явно ссылается на эти материалы или требует переноса знания из них.

- [`Reminiscence/`](./Reminiscence/)
  Объект: старые копии, заметки и исторические материалы вокруг прежних состояний проекта.
  Когда использовать: когда нужно проверить прежнюю реализацию, решение или контекст.

- [`ExternalBinaries/`](./ExternalBinaries/)
  Объект: неактивные бинарники без текущего подключения к активному проекту.
  Когда использовать: когда нужно сравнить поведение со старой сборкой или вернуться к потенциальной внешней численной зависимости.
