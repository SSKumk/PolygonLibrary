# Profile

Профильный проект для benchmark-сценариев геометрической библиотеки.

## Навигация

- [`Profile.csproj`](./Profile.csproj)
  Объект: проект профильных запусков `CGLibrary`.
  Когда использовать: когда нужно собрать или открыть benchmark-сценарии геометрической библиотеки.

- [`Benchmarks/`](./Benchmarks/)
  Объект: benchmark-классы для алгоритмов и структур `CGLibrary`.
  Когда использовать: когда нужно добавить, проверить или поддержать performance-сценарий.

- [`Наблюдения и результаты/`](./Наблюдения%20и%20результаты/)
  Объект: исторические заметки и результаты профильных наблюдений.
  Когда использовать: когда нужно понять контекст старого benchmark-а или сверить прошлые выводы.

## Не использовать

- Для LDG-профилей: они лежат в [`../../LDG/Profile/README.md`](../../LDG/Profile/README.md).
- Для постоянных regression-тестов: они лежат в [`../Tests/README.md`](../Tests/README.md).
