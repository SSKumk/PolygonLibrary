# MinkowskiDiff Research

Что это: исследовательские тесты и численные наблюдения для `MinkowskiDiff` и связанных с ним низкоуровневых алгоритмов.

Когда использовать: когда нужно изучать границы применимости, численную устойчивость и pathological cases, не смешивая их с обычным `basic/regression` слоем.
