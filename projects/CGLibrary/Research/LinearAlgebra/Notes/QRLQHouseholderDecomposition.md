# QR / LQ By Householder Reflections

## Постановка

### QR

Для матрицы

```text
A \in R^{d x m}, d >= m
```

нужно построить разложение

```text
A = Q R,
```

где

- `Q \in R^{d x d}` ортогональна:
  ```text
  Q^T Q = I;
  ```
- `R \in R^{d x m}` верхнетреугольна:
  ```text
  R_{ij} = 0 при i > j.
  ```

### LQ

Для матрицы

```text
A \in R^{m x d}
```

нужно построить разложение

```text
A = L Q,
```

где

- `L \in R^{m x d}` нижнетреугольна:
  ```text
  L_{ij} = 0 при j > i;
  ```
- `Q \in R^{d x d}` ортогональна.

### Инкрементальные обновления

Дана ортогональная матрица

```text
Q_cur \in R^{d x d}
```

и индекс `k`.

Нужно модифицировать только trailing block матрицы так, чтобы для заданного вектора `v`:

- в QR-update:
  ```text
  v^T Q_new = (*, ..., *, nonzero, 0, ..., 0);
  ```
- в LQ-update:
  ```text
  Q_new v = (*, ..., *, nonzero, 0, ..., 0)^T.
  ```

Во всех случаях нулевой хвост начинается после позиции `k`.

## Отражение Хаусхолдера

Для ненулевого вектора

```text
x \in R^n
```

строится отражение

```text
H = I - beta * u * u^T,
```

где

```text
u = x + sign(x_1) * ||x|| * e_1,
beta = 2 / (u^T u).
```

Тогда

```text
H x = (-sign(x_1) * ||x||, 0, ..., 0)^T.
```

Если требуется занулить не весь вектор, а только хвост начиная с позиции `k`, то отражение строится по вектору

```text
x_tail = (x_k, x_{k+1}, ..., x_{n-1}).
```

Затем `H` применяется только к соответствующему trailing block матрицы.

## QR-разложение

Пусть на шаге `k` рассматривается хвост `k`-го столбца матрицы `R`:

```text
r = (R_{k,k}, R_{k+1,k}, ..., R_{d-1,k})^T.
```

По `r` строится Householder reflector `H_k`.

Далее выполняется обновление

```text
R := H_k R
```

только на подматрице строк `k, ..., d-1` и столбцов `k, ..., m-1`.

После этого в `k`-м столбце матрицы `R` все элементы ниже диагонали зануляются.

Ортогональный множитель накапливается так, чтобы сохранялось равенство

```text
A = Q R.
```

Если обозначить накопленный множитель после шага `k` через `Q_k`, то используется обновление

```text
Q := Q H_k.
```

После завершения всех шагов получается:

```text
A = Q R,
Q^T Q = I,
R upper-triangular.
```

## LQ-разложение

Пусть на шаге `k` рассматривается хвост `k`-й строки матрицы `L`:

```text
l = (L_{k,k}, L_{k,k+1}, ..., L_{k,d-1}).
```

По `l` строится Householder reflector `H_k`.

Далее выполняется обновление

```text
L := L H_k
```

только на подматрице строк `k, ..., m-1` и столбцов `k, ..., d-1`.

После этого в `k`-й строке матрицы `L` все элементы правее диагонали зануляются.

Ортогональный множитель накапливается так, чтобы сохранялось равенство

```text
A = L Q.
```

То есть используется обновление

```text
Q := H_k Q.
```

После завершения всех шагов получается:

```text
A = L Q,
Q^T Q = I,
L lower-triangular.
```

## Инкрементальный QR-update

Дана ортогональная матрица `Q_cur` и вектор `v`.

Рассматривается вектор координат

```text
y = v^T Q_cur.
```

Берётся его хвост

```text
y_tail = (y_k, y_{k+1}, ..., y_{d-1}).
```

По этому хвосту строится reflector `H`.

Затем обновляется trailing column block:

```text
Q_new = Q_cur H.
```

Тогда

```text
v^T Q_new = y H = (*, ..., *, alpha, 0, ..., 0),
```

где `alpha != 0`, если `y_tail != 0`.

Если `y_tail = 0`, update не меняет матрицу.

## Инкрементальный LQ-update

Дана ортогональная матрица `Q_cur` и вектор `v`.

Рассматривается вектор

```text
y = Q_cur v.
```

Берётся его хвост

```text
y_tail = (y_k, y_{k+1}, ..., y_{d-1}).
```

По этому хвосту строится reflector `H`.

Затем обновляется trailing row block:

```text
Q_new = H Q_cur.
```

Тогда

```text
Q_new v = H y = (*, ..., *, alpha, 0, ..., 0)^T,
```

где `alpha != 0`, если `y_tail != 0`.

Если `y_tail = 0`, update не меняет матрицу.

## Общие алгебраические операции

Все четыре алгоритма опираются на три общие операции.

### 1. Построение Householder reflector по хвосту

По trailing part вектора строятся:

```text
u, beta, H = I - beta * u * u^T.
```

### 2. Применение reflector слева к подматрице

```text
A_sub := H A_sub.
```

Эта операция используется в:

- `QR_ByHouseholder`;
- `LQ_IncrementalUpdate`;
- накоплении `Q` в `LQ_ByHouseholder`.

### 3. Применение reflector справа к подматрице

```text
A_sub := A_sub H.
```

Эта операция используется в:

- `LQ_ByHouseholder`;
- `QR_IncrementalUpdate`;
- накоплении `Q` в `QR_ByHouseholder`.
