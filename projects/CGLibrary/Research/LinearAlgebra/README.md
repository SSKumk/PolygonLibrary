# LinearAlgebra

Материалы по текущим low-level алгоритмам линейной алгебры в `CGLibrary`.

## Когда использовать

- когда нужно разобрать внутренние алгоритмические заметки по `LinearBasis` и `Decomposition`;
- когда нужно сверить наблюдения по stability и diagnostic-поведению текущей реализации;
- когда нужно найти связь заметок с тестовыми research-сценариями.

## Навигация

- [`Notes/`](./Notes/)
  Объект: отобранные внутренние notes по `LinearBasis`, `QR/LQ` и связанным stability/diagnostic-вопросам.
  Когда использовать: когда нужно восстановить логику решений по low-level линейной алгебре без смешивания с внешним reference-слоем.
