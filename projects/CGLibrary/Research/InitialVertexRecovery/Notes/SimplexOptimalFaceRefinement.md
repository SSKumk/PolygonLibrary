# Simplex Optimal Face Refinement

Алгоритм используется как post-processing после `SimplexMethod` в
[`ConvexPolytop.cs`](../../../CGLibrary/GeometryND/Polyhedra/ConvexPolytop.cs), когда нужно получить не просто optimum-точку, а вершину исходного многогранника.

## Постановка

Дано:

- `HPs` - `Hrep` многогранника;
- `x` - допустимая optimum-точка, найденная `SimplexMethod`;
- `basisHPs` - гиперплоскости, восстановленные из `BasisInequalitiesID`.

Нужно:

- дойти от `x` до вершины многогранника;
- сохранить инвариант, что движение идёт вдоль лица, заданного текущим набором `basisHPs`.

## Идея

Берётся только simplex-basis, без полного пересчёта всех активных ограничений в стартовой точке.

Нормали `basisHPs` задают текущее подпространство ограничений. Вектор из ортогонального дополнения к этому подпространству лежит вдоль текущего лица. Если идти по этому направлению, то ближайшая новая гиперплоскость уменьшает размерность лица. Повторяя шаг, получаем полный ранг нормалей и, значит, вершину.

## Алгоритм

1. Построить `LinearBasisMutable` по нормалям `basisHPs`.
2. Если базис уже полный, текущая точка является вершиной.
3. Иначе взять направление
   - `d = normalsBasis.OrthogonalComplementVector()`.
4. Среди гиперплоскостей из `HPs`, которые ещё не входят в `basisHPs`, искать ближайшее пересечение только в направлении `+d`.
5. Для каждой такой гиперплоскости считать:
   - `den = hp.Normal * d`
   - `num = hp.ConstantTerm - hp.Normal * x`
   - `alpha = num / den`
6. Учитывать только случаи, где `den > 0` и `alpha > 0`, затем взять минимальное допустимое `alpha`.
7. Перейти в новую точку:
   - `x = x + alpha * d`.
8. Добавить одну найденную гиперплоскость в `basisHPs`.
9. Инкрементально добавить её нормаль в `LinearBasisMutable` через `AddVector(...)`.
10. Повторять шаги 2-9, пока базис нормалей не станет полным.
11. После достижения полного ранга восстановить вершину как решение системы по накопленным `basisHPs`.

## Инварианты

- используется именно simplex-basis, а не полный active set стартовой точки;
- на каждом шаге mutable-базис обновляется инкрементально;
- критерий остановки - полный ранг нормалей, а не просто количество гиперплоскостей.

## Практические замечания

- Вырожденная вершина допускается: после восстановления точки наружу можно вернуть полный active set, даже если в basis использовалось меньше ограничений.
- Алгоритм нужен именно как геометрическое доведение optimum-face точки до вершины; он не меняет контракт `SimplexMethod`.
