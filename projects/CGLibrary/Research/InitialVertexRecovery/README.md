# InitialVertexRecovery

Материалы по восстановлению стартовой вершины по `Hrep` через simplex-based seed.

## Когда использовать

- когда нужно разобрать внутренний алгоритм `FindInitialVertex_Simplex` / `RefineOptimalPointToVertex`;
- когда нужно сверить reasoning по доведению simplex-optimum до вершины;
- когда нужно связать алгоритмические заметки с покрытием `ConvexPolytop`.

## Навигация

- [`Notes/`](./Notes/)
  Объект: алгоритмические заметки по post-processing после `SimplexMethod` для восстановления вершины многогранника.
  Когда использовать: когда нужно уточнить шаги, инварианты и практические ограничения текущей реализации.
