# References

Каталог внешних источников, на которые опираются алгоритмы и геометрические конструкции библиотеки.

## Навигация

- [`Algorithms/README.md`](./Algorithms/README.md)
  Объект: ссылки на статьи и reference-материалы для алгоритмических слоёв библиотеки.
  Когда использовать: когда нужно найти источник для конкретного алгоритма или понять, на какую публикацию опирается его реализация.

- [`GeometryND/README.md`](./GeometryND/README.md)
  Объект: внешние материалы по многомерной геометрии и связанным объектам.
  Когда использовать: когда нужен математический источник не для алгоритма как такового, а для геометрических объектов и их генерации.

## Правила

- В эту ветку кладутся только внешние источники: статьи, preprint-версии, конспекты внешних источников и сопровождающие reference-материалы.
- Для каждой содержательной папки нужен локальный `README.md`, который отвечает на два вопроса:
  - что это за источник;
  - для какого алгоритма, объекта или участка кода он используется.
- Если источник большой или содержит несколько версий, в `README.md` нужно явно указать, какая версия считается рабочей для библиотеки.
