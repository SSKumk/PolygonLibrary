# Apps

Запускатели LDG, выделенные в отдельный слой активного проекта.

## Навигация

- [`Bridges/`](./Bridges/)
  Объект: консольный запускатель сценариев мостов.
  Когда использовать: когда нужно запускать и отлаживать bridge-сценарии поверх `LDG` и `CGLibrary`.

- [`Trajectories/`](./Trajectories/)
  Объект: консольный запускатель сценариев траекторий.
  Когда использовать: когда нужно запускать и отлаживать trajectory-сценарии поверх `LDG` и `CGLibrary`.
