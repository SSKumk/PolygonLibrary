# LDG Documentation

Документация по формату данных и организации файлов LDG.

## Навигация

- [`DataFormat.md`](./DataFormat.md)
  Объект: стандартная нотация полей и базовых типов в LDG-файлах.
  Когда использовать: когда нужно проверить синтаксис и соглашения перед чтением или правкой форматов.

- [`IOFormat/`](./IOFormat/)
  Объект: форматы конкретных входных файлов LDG (`Dynamics`, `Polytopes`, `TerminalSets`, `TrajectoryConfig`, `ProblemConfig`).
  Когда использовать: когда нужно сверить структуру конкретного файла ввода или исправить несовпадение формата.

- [`FolderStructure.md`](./FolderStructure.md)
  Объект: структура рабочих папок LDG.
  Когда использовать: когда нужно понять, как раскладывать файлы примеров и связанных данных.

- [`GameFolderStructure.md`](./GameFolderStructure.md)
  Объект: структура папки игры и связь служебных файлов.
  Когда использовать: когда нужно проверить состав файлов внутри одной игровой постановки.

- [`GameHashForming.md`](./GameHashForming.md)
  Объект: правило формирования хеша игры.
  Когда использовать: когда нужно сверить идентификацию и сравнение игровых конфигураций.

- [`VisualizationConfig.md`](./VisualizationConfig.md)
  Объект: формат конфигурации визуализации.
  Когда использовать: когда нужно настроить параметры визуализации для LDG-сценариев.

- [`Archive/`](./Archive/)
  Объект: исторические материалы по старым вариантам форматов.
  Когда использовать: когда нужно поднять контекст прошлых решений без переноса legacy-правил в активные документы.
