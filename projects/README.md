# Projects

Папка содержит активные проекты репозитория.

## Навигация

- [`CGLibrary/`](./CGLibrary/)
  Объект: основной активный проект библиотеки геометрических вычислений.
  Когда использовать: когда нужно менять актуальный код, тесты, документацию или рабочие списки задач.

- [`LDG/`](./LDG/)
  Объект: активный прикладной проект по линейным дифференциальным играм.
  Когда использовать: когда нужно менять LDG-ядро, запускатели, визуализацию, профилирование или ручные проверки LDG.
