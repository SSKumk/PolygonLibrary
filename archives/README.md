# Archives

Папка содержит архивные снимки старых состояний репозитория и связанных материалов.

## Навигация

- [`old-snapshots/`](./old-snapshots/)
  Объект: архивные `.7z`-снимки старых состояний `PolygonLibrary` и `AVLUtils`.
  Когда использовать: когда нужно восстановить или проверить исторический снимок без изменения активных слоёв.
